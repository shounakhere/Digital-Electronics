## How to Simulate Circuits

1. Download and install [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution/releases).
2. Clone this repository:

   ```bash
   git clone https://github.com/shounakhere/Digital-Electronics.git
   cd Digital-Electronics
   ```

3. Open any `.circ` file or inspect schematic diagrams in the `circuits/` folder.
4. Use `Simulate -> Ticks Enabled` or press `Ctrl + K` to cycle the clock.
